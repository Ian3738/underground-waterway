# 地底水道大冒險

小學英文課用的接水管遊戲。各組輪流答英文題，答對就能接水管、修水管、敲石頭或探照終點，把水接到寶藏。

- 遊戲方式：全班合作，或分道比賽
- 分道比賽的進行方式：輪流答題、同時作答（全部的組一起答，老師在大螢幕點各組答案）、平板連線（每組一台平板或手機輸入房間代碼加入，同時作答、各自挖水道）、速度賽（每台平板自動出不同題目，答對馬上挖，不用等別組）
- 水管平均派發：直管、彎管、三通各三張、十字一張一輪，手上盡量不重複
- 加碼玩法：限時答題、連勝獎勵、丟石頭給別組、搶答回合
- 八位角色可選，附背景音樂與音效
- 題目單字可以在「遊戲設定」裡自己改

直接打開 `index.html` 就能玩，不需要安裝任何東西。平板連線需要網路。
